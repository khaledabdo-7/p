# My English Presentation • Khaled

A clean, modern, interactive presentation web application built with **React**, **Tailwind CSS**, and **Framer Motion**.

Designed specifically for **A1 English Speaking Presentations** focusing on the **Present Simple Tense**.

---

## 🚀 Quick Start

From this directory (`level1-presentation`):

```bash
# Start local development server
npm run dev

# Or build and preview production release
npm run build
npm run preview
```

Open `http://localhost:5173` (or the port Vite outputs) in your browser.

## ✨ Interactive Features
1. **Slide Deck Presenter Mode:** Click **"Present Slides"** or use the shortcut to open a full-screen presenter modal with keyboard arrow navigation (`←` / `→` or `Space` / `Esc`).
2. **Text-to-Speech (TTS):** Native Web Speech audio playback with 0.9x speed tuned for clear pronunciation. Listen to individual cards, intro greeting, or entire sections.
3. **Present Simple Verb Highlighter:** Interactive toggle highlights all Present Simple verbs (*live, is, has, cooks, cleans, washes, wake up, study, etc.*) with hover grammatical notes.
4. **Rehearsal / Blind Practice Mode:** Toggle eye icon on any card to blur the text and test your memory before speaking aloud.
5. **Quick Copy:** One-click copy for cards and speaking scripts.
